## Concept build notes (site: burlington-capital/)
- Palette (BK): the logo is white on black only, so the site stays monochrome: logo #000000 → --ink #0b0b0c; logo #FFFFFF → --bone #f3f1ec; site warm grey #A8A6A1 → --acc/--stone (tints #d3cfc6 on dark, #6a665e on light). No other hue.
- Type: Hanken Grotesk (close to the site's halyard-display), Instrument Serif italic for single accent words, DM Mono labels.
- Logo: redrawn as an inline SVG of the official mark (rounded-square outline with BURLINGTON / CAPITAL / PARTNERS), since the official file is a 500px raster with a black box.
- Hero: the logo's rounded-square frame repeated in depth as a corridor; frames drift toward the viewer.
- Story: Customer First / People First / Partner First on one diagram of a company.
- Images used: both partner headshots (TN.jpg, MB.jpg; MB is 287px, so it is shown small and never enlarged).
- Images not used: the stock tunnel/metro and Unsplash photos on the home and focus pages (stock); portfolio logos (PDS webp 432px, Martin Pallet, Hinchcliff, Sokol: mixed formats and colours, so company names are set in type for one consistent treatment, rule BW).
